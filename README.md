# 봉 리플레이 매매 연습기

랜덤 종목의 과거 차트를 **정체를 숨긴 채** 보여주고, 캔들을 하루씩 넘기며
매수·매도 타이밍을 연습하는 도구. 미래 봉은 가려져 있고, 끝나면 정답(종목·시기) 공개.

## 실행

```bash
./run.sh
```

또는 `.venv/bin/streamlit run app.py` — 브라우저가 자동으로 열린다 (http://localhost:8501).

## 사용법

한 **세션** = 랜덤 종목 N개(기본 15개)를 차례로 플레이. 다 끝내면 매매 분석 리포트.

1. 사이드바에서 **세션 종목 수**(기본 15)와 **플레이 봉 수**(150~500)를 정한다
2. **[세션 시작]** — 첫 종목에서 시작 (종목명·날짜·봉 번호 숨김)
3. 과거 200봉이 보임. **[다음 봉]**으로 하루씩 전진 — 미래 봉은 가려짐
4. **[몰빵 매수]** — 보유 현금 전액으로 그 봉 종가에 매수 (한 종목당 진입 3회까지)
5. **[매도]** — 매도 비율(10~100%, 10단위) 슬라이더로 분할 매도
6. **[다음 종목]** — 보유분 자동 청산하고 자본·수익률을 이어 새 종목으로
7. **[지금 끝내기]** — 몇 종목을 했든 즉시 세션 종료 → 리포트
8. 차트를 드래그해 **추세선**을 자유롭게 그림 — 봉을 넘겨도 유지.
   차트 아래 **[선 N ✕]**로 하나씩 삭제, **[전체 삭제]**로 한꺼번에 삭제
9. 화면 아래 **수익률 추이** 그래프로 계좌 흐름 확인
10. 세션을 마치면 **결과 리포트** — 총수익률·승률·손익비 + 매매 코칭

- 시작 자본: 1,000만원 (종목을 갈아타도 자본·수익률 누적)
- 캔들: 상승 빨강 · 하락 파랑 (한국식) · 차트 하단에 거래량 막대

## 더블클릭 실행

`주식 매매 연습.app`을 더블클릭하면 터미널 없이 바로 실행된다.

## 구성

- `app.py` — Streamlit 앱 (리플레이 엔진 + 매매 + 수익률 그래프)
- `chart_component/` — 캔들차트 커스텀 컴포넌트 (추세선 자유 그리기·유지·개별 삭제)
- 데이터: FinanceDataReader (한국 주식 시세, 무료·API키 불필요)
- 차트: Plotly 캔들스틱

## 메모

- 수수료·세금·배당 미반영 (단순 시세 차익)
- 게임 상태는 앱을 닫으면 사라짐 (세션 메모리)
